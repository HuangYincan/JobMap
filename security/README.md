# Security Records

This directory contains the repository-tracked, redacted security records that are safe to review with code changes. Do not add secrets, personal data, credentials, session tokens, or weaponized exploit payloads.

- [`vulnerability-register.md`](vulnerability-register.md) — durable register for the 2026-09-01 full-repository quality/security scan and its remediation lifecycle.

The original detailed scan artifact is maintained separately in the local, ignored quality-scan workspace. This tracked register preserves the evidence and status needed for code review without restoring the private internal documentation tree.
