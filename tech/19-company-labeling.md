# 19 — 公司打标:tier 可见性 + category 国标大类

> 2026-08-17。LOD 过滤机制见 `tech/18` §2.2;数据管线见 `tech/roles/data/`。

## 1. tier:可见最小 zoom(0–21)

**模型**:每家公司一个 `tier` 值,含义 = 「可见最小缩放级别」。

```
zoom >= tier 时该公司在地图上显示 → 服务端 SQL 过滤:companies.tier <= :zoom
```

缩放级别连续变化时公司逐步涌现/消退,无档位跳变。zoom 取整传参
(前端 `lod.ts:maxTierForZoom(zoom) = floor(zoom)`,0–20;21 超界视为非法不过滤)。

| tier | 语义 | 示例(2026-08-17 打标口径) |
|---|---|---|
| 0 | 一直可见(任意 zoom) | 国际化名企:字节跳动/腾讯/阿里巴巴 |
| 1–3 | 全球/洲际级(zoom≥1 即显示) | 已启用:DeepSeek(1)/DJI 大疆(1)/SHEIN(1) |
| 4–5 | 国家级名企(全国缩到 zoom≥4 出现) | 百度/美团/京东/拼多多/网易/小米 |
| 6 | 省级名企(区域龙头) | 大疆/海康威视 |
| 7 | 城市名企 | 蚂蚁集团/网易杭州 |
| 8–11 | 中厂(知名但非头部) | CVTE/思谋科技/深势科技 |
| 12–16 | 小厂 | 缺省 12(未打标按此处理) |
| 17–20 | 微小/待定(几乎不显示) | — |
| 21 | 永不显示(zoom 最大 20,等价隐藏标记) | 数据标记/黑名单 |

**DB 缺省**:`companies.tier DEFAULT 12`(迁移 012)。缺省值的读路径兜底
(`recruitment-store.ts` / `recruitment-source.ts` / `search.ts` 均 `?? 12`)。

## 2. category:国标大类(GB/T 4754-2017)

企业类型按**国标《国民经济行业分类》GB/T 4754-2017 的大类 code**(2 位数字)
打标,不自定义。结构:门类 20 / 大类 97 / 中类 473 / 小类 1382
(来源:[国家统计局 2017 版修订说明](http://hazd.stats.gov.cn/dczs/wtjd232/2017/10/10/732.html))。

- `companies.category text NOT NULL DEFAULT 'other'`(迁移 012),无枚举约束,新类别零迁移。
- 门类(20 个)作为将来 UI 筛选的分组维度,不单独建列。
- 本次打标实际使用的大类见下表;未列出的类别按国标原文补充,不自行发明。

## 3. 打标规则(2026-08-17 批次)

1. **数据源**:`server/data/recruitment/{radar,official-career}/*.json`(680 家)。
   现成字段:`scale`(bigtech 9 / unicorn 15 / enterprise 652 / startup 4)、
   `industries`(internet 198 / manufacturing 142 / finance 55 / other 204 …)。
2. **tier 基准(scale)**:bigtech → 0–5;unicorn → 5–7;enterprise → 8–12;
   startup → 10–14;再按公司知名度/业务覆盖微调。
3. **category 基准(industries)**:按 §2.1 表映射;`other` 与 `manufacturing`
   按公司名逐个判断细分大类。
4. **流程**:LLM(主会话)批量分类 → 产出 `{slug: {tier, category}}` 全量表
   → **用户审核** → 写回 drops JSON(更新 `tier`,新增 `category`)。
5. **入库**:`npm run import:seed:apply`(用户执行)把 tier/category 落
   `companies` 表;geocode 配额重置后先 `npm run geocode:sites:apply` 补全国坐标。
