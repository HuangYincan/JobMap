## PRD 模板

每个新功能需要一份 PRD,包含:

1. **背景与目标**:为什么做这个功能
2. **目标用户**:谁会用
3. **核心需求**:用户要解决什么问题
4. **功能描述**:功能清单 + 优先级
5. **交互流程**:用户如何操作(附流程图)
6. **验收标准**:如何判断功能完成
7. **数据指标**:如何衡量成功
8. **上线计划**:发布时间 + 灰度策略
