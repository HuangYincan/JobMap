# Workstream w1 — 隐藏百度地图左下角水印(anchorBL / logo_hd.png)

## 背景

百度地图 BMapGL 会在左下角自动注入版权水印 `.BMap_anchorBL` 内的 `<img src=".../logo_hd.png">`(高度 21px)。项目惯例:**厂商版权/水印类 ToS 敏感元素一律由 `map-shell.module.css` 的 CSS 隐藏**(高德 `.amap-logo` L60、腾讯 `img[src*="logo_def.png"]` L77、百度版权 `.BMap_cpyCtrl` L85),JS 只负责 zoom/指北针等遮挡控件(`hideBaiduDefaultControls`)。当前 **anchorBL 水印是全项目唯一漏网的厂商水印**(src/tests 对 anchorBL/logo_hd 零命中)——本次补齐。

## 任务(worktree 已预建,只改这一个文件 + 一个测试文件)

### 改动 1:CSS — `server/src/components/map-shell.module.css`

在百度控件块(约 L82-89,`.BMap_cpyCtrl` / `.BMap_omView` / `.BMap_zoomCtrl` 附近)内追加一条规则,与腾讯水印写法同构:

```css
/* 百度左下角 logo 水印隐藏(anchorBL,SDK 注入,与腾讯 logo_def 同款处理) */
.mapCanvas :global(img[src*="logo_hd"]) {
  display: none !important;
}
```

要点:
- **必须用 `img[src*="logo_hd"]` 而非 `.BMap_anchorBL`**:anchorBL 是左下锚容器,引擎自建比例尺 `.BMap_scaleCtrl` 也落在左下,绝不能误伤(现有测试明确钉住「比例尺不误伤」)。子串匹配同时覆盖 `logo_hd.png` / `logo_hd@2x.png` 变体。
- 放在百度块内,注释写清来源(SDK 注入、与腾讯/高德同款处理)。
- **不碰** `.BMap_scaleCtrl`(保留)、不碰其他引擎样式、不碰 `globals.css`。

### 改动 2:测试 — `server/tests/component-contracts.test.mjs`

在「mapCanvas 层级隔离契约」测试(约 L1339,已有 `.BMap_cpyCtrl` / `.BMap_omView` / `.BMap_zoomCtrl` 断言处)追加一条同款断言:

```js
assert.match(css, /img\[src\*="logo_hd"\]/, '百度左下角 logo 水印必须由 map-shell CSS 隐藏');
```

与现有断言格式保持一致(先读该文件相应段落,照抄上下文风格)。

### 边界

- **不碰**:`server/src/lib/map-engine/baidu/baidu-engine.ts`(无需 JS 层——BMapGL 同步建 DOM,CSS 已足够;新增 JS 会触碰「版权不误伤」测试 `map-engine-baidu.test.mjs` L1298 的断言,扩大改动面)、高德/腾讯样式、比例尺、地图引擎逻辑、任何现有 UI 设计语义。
