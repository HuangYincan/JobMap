## 短路判定实现摘要

```
QUOTA_SHORT_CIRCUIT_N = 5
isQuotaClassReason(r) = r ∈ { 'quota', 'baidu-status:302', 'no-key' }
shouldShortCircuitQuota(history, n) = history 末 n 个条目全部 isQuotaClassReason
主循环每站:
  unresolved(reason) → recordOutcome(reason); 若 shouldShortCircuit → break mainLoop
  resolved           → recordOutcome(null)      # 冲窗口,不误停
尾部: REPORT 照常打印; shortCircuited → QUOTA_EXHAUSTED 行 + exit(2)
```
