## 任务

给地点检索加**结果缓存(memo)**,配额利用率提升数倍:

1. 读 `server/scripts/geocode-sites-apply.mjs` 的 `searchCompanyPoi`(L155-165)与主循环(L149-330)。
2. 设计(自裁,最小改动):
   - `searchCompanyPoi` 按 `(query, region)` 做 memo:**只缓存成功命中**(ok && poi 非空);失败/空结果/quota 类失败**绝不缓存**(配额恢复后必须重新尝试,缓存旧失败会永久卡死站点)。
   - memo 作用域:进程内一次运行;同 query+region 的后续站点直接复用第一个命中 POI(regeo 验证仍对每个站点执行——同一 POI 的 regeo 结果可一并缓存,或保留现有 per-site regeo 均可,自裁,优先简单正确)。

   - 边界:query 含公司名 + 城市名(target.city 已是城市),memo key 必须精确;公司名相同但城市不同 → 不同 key。
3. **测试**:`server/tests/` 新增单元测试覆盖 memo 行为(同 query+region 第二次不发出请求 / 失败结果不缓存 / 不同 region 不串)。测试风格对齐现有 vitest(可对 `placeTextSearchRest` 注入 stub 计数)。
