# Workstream w2 — 修复「首次点击公司 POI 后视角切回/停在杭州」

## 背景(已查明的根因,2026-08-20 boss 派发,Explore 浏览器插桩实测)

**根因 = 首次点击的相机移动意图被 `geoSettled` 门控静默吞掉,geolocation 晚落地又被 `hasInteractedRef` 拦住补飞——首点视角停在杭州默认中心;第二次点击 geoSettled=true,flyTo 生效,所以「第二次正常」。**

时序(用户环境 geolocation 慢,1–5s 才 settle):
1. 地图以杭州初始中心创建(`map-shell.tsx:480`,zoom 13)。geolocation 挂起。
2. 首点公司 marker:`onMarkerClick`(1413-1434)只置 `hasInteractedRef=true`(1415)+ `setSelectedId`(1425)+ `setDetailPoi`(1428),设计上不 flyTo。
3. 点详情卡/列表卡 → `onOpenDetail`(2194-2203)与 `handleSelect`(1438-1447)的 flyTo 前有门控 `if (!mapReady || !geoSettled) return;`(1443-1444、2198)——首点落在 geoSettled=false 窗口 → **flyTo 被静默丢弃**,相机留在杭州初始中心。
4. geolocation 随后 resolve:`setCenter(userPos)+setZoom(15)`(520-522)被 `!hasInteractedRef` 门控(519)拦住 → 既不飞用户也不飞公司 → 用户感知「点了公司,视角(仍/又)在杭州」。

已排除:hasInteractedRef 未置位、受控 viewState 被杭州覆盖、mode cache restore 还原中心(restore 不含 center/zoom,use-mode-cache-restore.ts:49-68)、ws-v 池分离重放初始 viewState。地图全流程只创建一次(插桩实测 1 CREATE / 0 DESTROY)。
