# Workstream b2 — 修复公司 POI 屏闪(marker 只添加一次,跨视口保留实例)

## 背景(boss 2026-08-20 Explore 查明,file:line 均已核实)

用户症状:公司 POI 随视角变化经常屏闪(猜测:marker 被反复删除/添加)。**猜对了。**

**根因:设计注释与实现不符。** 多处注释声明「catalog 是 marker 源、只增不减」
(map-shell.tsx:176-178、:1156-1158;use-work-viewport.ts:169-172),但实际数据流:

```
视口批次 → listCatalogRef.current = batch(整体替换)   use-work-viewport.ts:200-201
        → setListCatalog(batch)
        → catalog 只并入(mergePoisById,只增)         use-work-viewport.ts:203-205
pois = runPOIPipeline(work && listCatalog.length>0 ? listCatalog : catalog)  map-shell.tsx:1159
markerPois = clusterState ? individual : mapPois       map-shell.tsx:1247-1250
usePOIMap(map, { pois: markerPois })                   map-shell.tsx:1427
```

work 模式下 marker 控制器收到的是**整体替换的 listCatalog**:每次 moveend/zoomend 防抖加载
(use-work-viewport.ts:174-219)产生全新 id 集合 → `setPOIs` 差分(map-markers.ts:557-576):
**离开视口的公司全部 removeMarker,进入视口的全部新建 marker**(每次平移/缩放都销毁重建,
AMap marker DOM 反复插拔 = 屏闪主因)。markers Map(map-markers.ts:345)保留 poiId→实例,
但只对同批次内生效。

次要来源:①favicon img 每次重建重新拉取(map-markers.ts:163-167 徽章内联 `<img>`);②zoom 变化
改 `maxTierForZoom`(lod.ts:26-33)过滤 → 成员变化同样 remove+add;③zoom≤8 聚合边界
(map-shell.tsx:1194-1250)整批销毁聚合徽章/个体 pin 互斥重建。

**不动点**(已是正确骨架):`applyStyle` 的 `markerStates` 早退(map-markers.ts:355、482)、
`setPOIs` 存量更新路径(:564-573 只 setPosition)。
