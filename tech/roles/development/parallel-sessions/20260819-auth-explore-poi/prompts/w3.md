# WS w3 — POI 电话/评价数据展示修复(poi-data-ux)

> 批次:20260819-auth-explore-poi | worktree: `/Users/acccan/dm-wt-w3`(已预建,分支 `fix/poi-data-ux`)

## 背景与根因(已探明,勿再大范围排查)

- POI 表 `hz_pois`(`db/migrations/013_hangzhou_pois.sql:17-45`),`tel` 是 **text 列**,但源 CSV 空电话写成字面量 `'[]'`(`/Users/acccan/Downloads/杭州市/杭州市POI.csv`),实测 1,006,158 行中 **697,546 行(69.3%)`tel = '[]'`**、0 个 NULL。导入器 `parseNumericCell` 会清 `'[]'`,但 tel 不清:`hz-poi-import.ts:180` `tel: (raw.tel || '').trim() || undefined` → 原样入库。
- API 侧:`hzRowToDomainPoi`(`server/src/lib/hz-poi-store.ts:97-122`,tel 映射在 :119)直接透传;AMap JS-API 路径 `normalizeAMapPOI` `tel: raw.tel || undefined`(`server/src/lib/amap-api.ts:222`)——空数组 `[]` 是 truthy,也会透传。
- 前端:poi-card **不渲染**电话;poi-detail.tsx:123 `<InfoRow label={t("phone")} value={poi.tel} />`;`InfoRow`(`poi-detail.tsx:330-338`)只跳过 falsy,`'[]'` 是真值 → 用户看到「电话 []」。
- 评价:DB **无** reviews 表/reviewCount 列/URL 列;本地 POI 永远没有评价数据。「暂无详细评价」= i18n `noReviews`(`i18n.ts:227`),渲染在 `poi-detail.tsx:282`(rating/reviewCount 存在但无 review 文本时显示)。
- AMap JS-API 路径**有**评价:`normalizeAMapPOI` 从 `reviews`/`comment`/`biz_ext.comment` 推 reviewCount + `parseAMapReviews`(`amap-api.ts:229-246`,最多 5 条)。搜索只用 PlaceSearch,无 getDetails。
- 可构造的评价页 URL:`https://www.amap.com/place/<poiid>`,poiid = `DomainPOI.id`(`hz-poi-store.ts:107` 即 `poi_id`)。**注意**:AMap 回退 POI 的合成 id(`amap-${lng}-${lat}-${name}`,`amap-api.ts:206,432`)不是真 poiid,**不能**拿来拼链接。
- 前端类型 `DomainPOI`(`server/src/lib/types.ts:67-89`):已有 `tel?`(:82)、`rating?`、`reviewCount?`(:86)、`reviews?: PlaceReview[]`(:88)。

## 任务(用户需求)

1. **电话 `[]` 不显示**:
   - 导入器 `hz-poi-import.ts:180`:tel 空值(空串/`'[]'`/数组空)统一转 `undefined`(照 `parseNumericCell` 风格)。
   - 防御性清洗(即使旧数据未重导也能正确展示):
     - `hz-poi-store.ts:119`:`tel` 为 `'[]'`、空串、空数组时输出 `undefined`。
     - `amap-api.ts:222`:空数组/空串 → `undefined`。
     - `poi-detail.tsx` InfoRow(或调用处):把 `'[]'`、空数组当空值处理(不渲染电话行)。选最小 diff、与组件风格一致的方案。
   - 数据库脏数据清理(re-import / SQL UPDATE)是 **Env-only,不要执行**,boss 记 deferred。
2. **评价展示**:
   - 源数据有 review/reviewCount 的(AMap 路径已填充 `poi.reviews` ≤5 与 `reviewCount`)→ 正常渲染(现状已有,保持)。
   - 本地 POI(无任何评价数据)且 **`poi.id` 是真 poiid**(不以 `amap-` 开头)时:`poi-detail.tsx` 的 ReviewSection(`:245-286`)在「暂无详细评价」处/旁展示蓝色「查看评价」链接 → `https://www.amap.com/place/${poi.id}`,`target="_blank" rel="noreferrer"`,沿用品牌蓝 `#007AFF`(小字可用 `--blue-ink`)。新建 i18n 键 `viewReviews`(zh: 查看评价 / en: View reviews)。
   - 合成 id(`amap-` 前缀)不显示链接,维持现状(仅「暂无详细评价」或直接不显示,按现有逻辑)。
   - 链接样式参照项目现有 text-link/蓝色链接样式(查 poi-detail.module.css 里已有的 link 风格,如无则仿 secondary-sidebar / recent-panel 的 `.textBtn` 风格加一个 `.reviewLink`)。布局 ASCII:
     ```
     评分 ★ 4.2   ·  123 条评价(如有 reviewCount)
     ─────────────────────────────
     暂无详细评价    [查看评价 →] (blue link,12px)
     ```
