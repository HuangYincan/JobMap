## 背景与根因(已探明,勿再大范围排查)

### Bug 1:移动端打开 profile 继承列表滚动位置
- 滚动容器是常驻挂载的 `<div ref={drawerContentRef} className={styles.drawerContent}>`(`src/components/map-shell.tsx:2394`,CSS `overflow: auto`,`map-shell.module.css:1238-1247`)。`mobileSheet` 切换时该 div 不卸载,`scrollTop` 从 POI 列表带到 account/profile 面板。
- 打开头像入口:`map-shell.tsx:2290-2303`(toolbar)与 `:2348-2361`(搜索行)→ `openMobileAccount`(`map-shell.tsx:1681-1694`):只设 `mobileSheet="account"`、`drawer="full"`、清 detailPoi/mobileJd,**无 scroll 重置**。
- 全库无 `scrollTo(0)` / `scrollIntoView`;`drawerScrollRef` 只在详情保存/恢复路径用(`:2594`、`:1786-1790`)。

**修复**:在 `openMobileAccount` 里(或 `mobileSheet` 切换到非 explore 面板时)重置 `drawerContentRef.current.scrollTop = 0`。保持现有设计语义(只是重置滚动),不改变布局。

### Bug 2:展开侧控栏,搜索框有文本时失焦后文本不可见
- 左栏搜索框在 `map-shell.tsx:1938-1965`,input `:1945-1964`,`value={query}` 受控,`query` 状态在 `map-shell.tsx:215`。**没有任何代码在 blur 时清空状态**——是 CSS 可见性问题:
- `map-shell.module.css:391-397` `.searchBox input { opacity: 0; position: absolute; … }`,仅 `.searchBox:focus-within input { opacity: 1 }`(`:399-401`);fallback 标签「搜索」只在 `!query` 时渲染(`map-shell.tsx:1944`)。于是:有文本 + 失焦 → input 透明 且 标签不渲染 → 看起来文本消失(重聚焦又回来,状态没丢)。
- SecondarySidebar 自己的搜索 input 不受影响(常显)。

**修复**:展开状态下输入框文字常显——让 `query` 非空或侧控栏展开时 `opacity: 1`(例如给 `.searchBox` 加展开态 class 或在 `.searchBox input` 规则里加 `:not(:placeholder-shown)` 类方案;选与现有 CSS 结构一致、最小 diff 的方案)。**不要**改布局/交互语义:折叠态视觉行为保持不变(折叠只显示图标)。若采用加 class 方案,注意 `query` 非空但折叠时保持现状(折叠不显文本,符合现有设计)。
