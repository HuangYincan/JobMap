### 验收清单

**A. 探索「加载更多」(桌面)**
- 打开探索模式(搜索任意词或点击探索入口)→ 二级卡片列表(resultHeader)右端应有蓝色「加载更多」按钮;滚动列表到底也会继续加载(哨兵仍在)。
- 点击「加载更多」→ 列表持续增量;到底后按钮消失,显示「── 没有更多结果 ──」。
- 断网/失败场景(可 DevTools Network offline 模拟)→ 不再永久停在"没有更多",footer 显示可重试。

**B. 密码登录/注册(桌面 + 移动 ≤720px)**

- 重启 dev server 后账号仍在(验证迁移已生效的持久化)。
