## 任务

**Bug 1 — logo 垂直居中**
- 位置:`map-shell.tsx:1800-1812`(品牌行 brandRow,含 Logo 24px + 「地图」+ BETA pill)
  在 `.menuWrap`(1799)内;折叠按钮是兄弟(1813-1823,absolute 定位)。
- 根因:`map-shell.module.css:191-196` `.menuWrap { position:relative; flex:0 0 42px; height:42px }`
  **不是 flex 容器**。品牌行(24px 高)作为 block 子元素顶部对齐,而折叠按钮 absolute
  垂直居中(y 21),两者差 ~9px。
- 修复:`menuWrap` 改为 `display:flex; align-items:center`(品牌行垂直居中),同时确保
  折叠按钮的 absolute 定位不受影响(保持 `top:0` 居中行为)。
- 验证:展开态(215px)logo/文本/BETA 在 42px 行内垂直居中;折叠态不变。

**Bug 2 — 邮箱溢出**
- 位置:`map-shell.tsx:1923-1928`(`.profileCopy` 含 displayName + accountLabel);
  CSS `map-shell.module.css:669-684`。
- 根因:展开宽 276→215px 后 `.profileCopy` 内容宽仅 ~102px;`.profileCopy`/`small` 有
  `white-space:nowrap` 但**无 `overflow:hidden`、无 `text-overflow:ellipsis`**。
- 修复:`.profileCopy`(及 strong/small)加 `overflow:hidden; text-overflow:ellipsis`;
  确保长邮箱截断显示省略号,不溢出侧栏边缘。
- 验证:超长邮箱(如 40+ 字符)显示 `...`;正常邮箱不受影响。
