## 任务

**Bug 3 — 身份卡塌陷**
- 位置:`account-panel.tsx:186-206`(`.identityCard`,头像 64px + identityName + accountLabel);
  CSS `account-panel.module.css`。
- 根因:`.sidebar`(34-52)是 `flex column; overflow:auto; height:100%`;`.card`(102-107)带
  `overflow:hidden` 成为 flex 项 → **flex 自动最小高度坍缩到 0**(flex 规则:item overflow
  非 visible 时无 content-based min)。`.identityCard`(224-231)无 flex-shrink/min-height,
  面板内容超高时吸收全部负空间被压缩,overflow:hidden 裁剪头像/名字/邮箱。
- 修复:`.identityCard` 加 `flex-shrink:0`(或等价 min-height),使其不被压缩。
- 验证:面板内容多时身份卡完整显示,不截断;正常内容不受影响。

**Bug 4 — 求职偏好改下拉(布局已批准)**

  `box-shadow: var(--shadow)`(深色模式同步,参照 sort-selector.module.css:47-63,107-110)。

- 交互细节:触发钮行内右对齐;点外关闭(pointerdown 监听,参照 SortSelector 31-52);
