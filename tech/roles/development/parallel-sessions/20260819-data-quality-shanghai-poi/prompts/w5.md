## 需求(用户原话)

「收藏图层的启停存在严重bug,会导致所有poi消失」

## 根因(已探明,勿再大范围排查)

- `handleToggleSavedOverlay`(`src/components/map-shell.tsx:1376-1398`):**ON 时**执行相机移动——`overlayBounds(overlayPois)` + `map.setBounds(...)`(:1391;fallback setCenter :1397)——这是 bbf1e91「fit its pins」引入的。OFF 分支(:1384 `if (!next) return;`)是纯状态切换,本身无害。
- `map.setBounds` 触发 AMap `moveend`/`zoomend` → `onViewChange`(:1029-1031)调度 debounce 800ms 的**视口 replace loader**(`map-shell.tsx:906-1026`):`existing: []` 整体替换目录(:960-961 work / :1008-1009 domain)。
- 收藏 pin 的视口往往是退化/稀疏视野(单 pin → `overlayBounds` sw==ne → 拉满 zoom → 0 行;或 pin 在 DB 覆盖区外)→ 新批次 = `[]` → `setCatalog([])` → `setPOIs([])` 按 id diff **删光所有 marker**(map-markers.ts:389-393),列表同步清空。**OFF 时看到的「全消失」是 ON 清空后的残局**(此时地图只剩 overlay pin,OFF 把它们也摘了,且无任何 refetch 恢复)。
- 同型交互:`handlePickSaved`(:1286-1305)flyToLocation 也会触发视口 replace,单 pin 落入空视口时同样可能清空。

   - 方案 B:直接删掉 :1384-1397 的相机移动块(恢复 bbf1e91 前纯状态切换)。若选 B,汇报里说明 fit-to-pins 被移除(可后续以安全方式回归)。
