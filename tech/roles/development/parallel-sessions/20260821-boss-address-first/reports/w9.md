## 识别逻辑摘要

中心钉点站(±0.0005 命中 CITY_CENTERS)按地址分流:
- 地址非空且非城市名(街道地址 / 城市列表占位)→ `siteNeedsGeocode = true` → 进 apply 计划;
- 地址为空或城市名(上海 / 上海市 / 仅含城市名)→ false → 留在中心(占位合理)。

apply 主循环适配检查(**无需改脚本**,已确认):中心站带街道地址 → `siteHasStreetAddress=true` 且
`addressConflictsWithCity=false` → 走 `geocodeAddressRest` 地址 geocode 分支;
城市列表占位地址 → `siteHasStreetAddress=false` → 走公司名 place-search 分支。
`siteHasStreetAddress`「上海市黄浦区马当路388号」= true、「三亚市」= false,原逻辑未动。
