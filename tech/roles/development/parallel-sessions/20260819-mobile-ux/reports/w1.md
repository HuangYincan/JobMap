## 遇到的问题

1. **桌面端回归(复核时发现并修复)**:`detailPoi` 在桌面端同样成立(左侧栏打开详情),若
   `.topToolsHidden` 与 scale 显隐不限视口,会把桌面 top-right compass / bottom-left scale 一并隐藏。
   → `.topToolsHidden` 包 `@media (max-width:767px)`;scale 显隐 effect 加 `window.innerWidth > 767` 提前返回,
   插件/resize 初始同步加 `window.innerWidth <= 767` 守卫。已记入 `tech/16-bug-fixes.md`。
2. `map-constants.ts` 的 `DRAWER_FULL_RATIO` 检查:当前树该文件并不含此常量(grep 全仓仅 docs 提及),
   无死常量需清理,`map-constants.ts` 零改动。
3. `svh` vs `window.innerHeight` 口径:CSS 用 `100svh`,JS 阈值用 `window.innerHeight`。真机浏览器 chrome
   收起时二者可能差几十 px,但 JS 松手判定与拖拽阈值同口径(内部自洽),且与原有 `86svh` 对比同型风险,
   不做额外处理。
