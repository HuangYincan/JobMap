## 任务

### 1. 全开高度 → 指南针中心
- `.drawerFull` 高度改为:顶边 = 指南针中心 Y,即
  `height: calc(100svh - max(12px, env(safe-area-inset-top)) - 20px)`。
- 同步 `.mobileDrawer` 的 `max-height:86svh`(1095-1115)→ 放开到同样的 calc(否则 max-height 会截断),
  保持 `min-height:90px`。
- **拖拽一致性**:`map-shell.tsx:1765-1767` 全开阈值从 `h >= vh*0.86` 改为「抽屉顶边到指南针中心」
  (即 `h >= vh - (max(12px, safe-area-top) + 20px)`,safe-area-top 运行时取
  `env(safe-area-inset-top)` 的解析值,可用 `Number(getComputedStyle(document.documentElement).getPropertyValue('--safe-area-top')) || 0` 或直接 0 兜底)。
  `map-constants.ts` 的 `DRAWER_FULL_RATIO` 同步(改为匹配的 px 值或保留 ratio 但按新口径换算),
  避免拖拽放手后 snap 回错误高度。
- 保持 `.drawerHalf`/`.drawerMini` 不变;`cycleDrawer`(1721, mini→half→full→mini)不变。
- 布局图(目标,移动端):
```

half / mini 状态:compass + scale + locate 照常显示(不变)。
```

### 2. 全开隐藏指南针 + 比例尺
- 条件:`drawer === "full" || !!detailPoi`(与 drawerFull 类同条件,2144)。
- **指南针(及新增定位按钮)**:`.topTools` 整组隐藏——给 topTools 加状态类(如 `topToolsHidden`),
  条件满足时挂上;过渡 ~200ms(opacity/visibility)。注意 `.topTools` 是 `.mobileDrawer` 的兄弟,
  需在 map-shell.tsx 里条件化 className,不能只靠兄弟选择器。
- **比例尺**:新增 effect,监听同一条件:`scaleControl?.show()/hide()`(或 `setVisible`),空指针守卫;
  缩放/模式变化不覆盖。effect 挂载时同步一次当前状态。
- 布局/行为:返回 half/mini 时两者恢复显示。
