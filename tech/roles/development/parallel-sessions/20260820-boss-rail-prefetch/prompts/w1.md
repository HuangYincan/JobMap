## 背景

用户报告 bug:第一次点击侧控栏(左侧 rail)中任何会弹出二级卡片的 item(Profile / Saved / Recent / Layers / Explore),**整个网页会刷新一次**,后续点击正常。用户体验差,要求"初次加载不刷新"。

根因已由 boss 双代理探索确认(证据链完整,不必重查,但欢迎抽查):

1. **应用代码零刷新路径**:全 `server/src` 无 router.refresh / window.location / form submit / history API。
2. 真凶 = **dev 模式(Turbopack)下 `next/dynamic` 懒加载 chunk 的按需编译**:
   - 8 个面板全部 `dynamic(() => import(...))` 声明于 `/Users/acccan/dm-wt-w1/server/src/components/map-shell.tsx` **L48-55**(POIDetailView / JdPanel / AuthModal / ProfilePanel / RecentPanel / SavedList / SavedPanel / LayersPanel),无 `ssr:false`、无 loading 兜底。
   - 冷启动 dev 服务器上,首点触发 chunk 按需编译;Next dev 客户端 `hot-reloader-app.js` 的 `performFullReload`(`window.location.reload()`)在编译完成后整页刷新。编译后 chunk 进缓存 → 「首点刷新、之后正常」完全吻合。
   - 偶发性解释:`prefetchRail(panel)`(map-shell.tsx **L57-67**)在 rail 按钮 `onMouseEnter`/`onFocus` 时 `void import(...)` 预载(挂载点 L2102-2103、2119-2120、2131-2132、2142-2143、2155-2156)—— 先悬停再点就不会刷新。
   - 生产构建预编译,不受影响。
