// server/src/lib/i18n.ts(将由 w1 新增)

## 任务

### 1. `server/src/components/filter-panel.tsx`

全文扫描所有 `config.label` / `option.label` / `currentLabel` / `option.labelEn` 相关渲染与 aria 属性,改为 `uiLabel(config, lang)` / `uiLabel(option, lang)`。已知点(以实际代码为准,覆盖全部):

- `SelectControl`:`config.label`(标签 span + aria-labelledby 目标)、`currentLabel`(`options.find(...)?.label ?? allLabel` 处)、下拉 `aria-label={config.label}`、每个 option 按钮文本 `option.label`。
- 其他控件(MultiSelectControl / TaxonomyControl / chips / toggle / date 等):所有 label 渲染 + `aria-label` + group `aria-label` 走 `uiLabel`。
- **递归 children**:taxonomy 树的 `children` 选项 label 也要走 `uiLabel`(flatten 或递归处)。
- `unit` 显示处(如 `${config.unit}` 后缀):en 时用 `config.unitEn ?? config.unit`(同样处理,可内联三目)。
- `allLabel`(已是 `lang === "zh" ? "全部" : "All"`)不动。
- 组件已接收 `lang?: Language` 且默认为 `"zh"`——保持,不要改 props 契约。

### 2. `server/src/components/sort-selector.tsx`

- 触发钮文本 `current.label` → `uiLabel(current, lang)`(注意 `current` 可能 undefined,保持现有空安全写法)。
- 下拉每个 option 按钮 `option.label` → `uiLabel(option, lang)`。
- `aria-label={t("sort", lang)}` 已适配,不动。
