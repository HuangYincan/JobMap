### 2. `server/src/lib/i18n.ts` — 辅助函数

在 `t()` 附近加(唯一契约,WS-2/WS-3 依赖此签名):

```ts
/** 选项/筛选标签:英文 UI 用 labelEn,缺失回退中文 label。 */
export function uiLabel(
  o: { label: string; labelEn?: string },
  lang: Language,
): string {
  return lang === "en" ? (o.labelEn ?? o.label) : o.label;
}
```
