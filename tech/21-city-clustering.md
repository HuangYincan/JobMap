# 21 — 城市聚合(全国/省级视野密度管理)

> 2026-08-17 方案草案,待用户批准后实现(前端硬性规则:先布局图后代码)。

## 1. 问题

tier 模型落地后:全国视野(zoom ≤ 5)显示 tier ≤ 5 的 ~70 家、省级(6–7)
显示 ~375 家,分布在北京/上海/杭州/深圳等城市,同城 10–50 家 pin 重叠,
无法点选,视觉是"一坨"。

## 2. 交互设计(ASCII 布局图)

```
zoom ≤ 7(全国 / 省级视野)               zoom ≥ 8(城市级,自动展开)
┌───────────────────────────┐          ┌───────────────────────────┐
│                           │          │                           │
│         ╭────╮            │          │              ╭───╮        │
│    ╭────┤北京 │────╮       │          │         ╭───┤字节│        │
│    │ 12 │    │ 8  │       │          │    ╭────┤   ├───╮        │
│    ╰────╯    ╰────╯       │          │    │阿里│   │腾讯│        │
│    ╭────╮    ╭────╮       │          │    ├────╯   ╰───╯        │
│    │杭州 │    │深圳 │       │          │    │小米│                │
│    │ 15 │    │ 10 │       │          │    ╰────╯                │
│    ╰────╯    ╰────╯       │          │                          │
│                           │          │                          │
└───────────────────────────┘          └───────────────────────────┘
  聚合徽章:圆形,品牌蓝 #007AFF 描边,   点击聚合徽章 →
  白色底 + 「城市名 N」(如「北京 12」)    地图平滑缩放到该城市,zoom 11,
                                        聚合徽章消失,个体 pin 出现
```

**规则**:
1. 触发:work 模式,`zoom <= 7`(全国/省级)时启用;`zoom > 7` 自动切回个体 pin。
2. 聚合粒度:`site.city`(公司办公点城市);无 city 的 pin 保持个体。
3. 徽章点击 → `map.setZoomAndCenter(11, 城市中心点)`,城市中心从该城
   所有 pin 坐标取均值(或 DB city_code 中心,先均值)。
4. 徽章 hover 显示城市 + 数量;点击仅下钻,不弹卡片(卡片由个体 pin 负责)。
5. 与现有交互零冲突:视口增量加载、选中高亮、LOD 过滤全部在聚合层之上工作。

## 3. 实现(一切皆插件)

| 模块 | 内容 | 测试 |
|---|---|---|
| `lib/city-cluster.ts`(新) | 纯函数:输入 POI[] + zoom,输出聚合组 `{city, count, lng, lat}[]`;zoom 阈值常量 | 单测:分组/计数/中心点/阈值切换 |
| `lib/map-markers.ts`(扩展) | `createCityClusterMarkers(map, groups)`:聚合徽章 AMap.Marker(复用品牌徽章 HTML 样式,圆形计数) | — |
| `map-shell.tsx`(接线) | work 模式 zoom 变化时在两种 marker 模式间切换;徽章点击 setZoomAndCenter | Playwright 验收 |

**插件缝**:聚合是 map-markers 的第二种渲染模式,不侵入 POI 数据流;
未来"按 category 聚合"(如全国视野按行业分组)可复用同一 controller。

## 4. 不做的事(本期)

- 不做 AMap MarkerClusterer(自动网格聚合)——样式与"城市"语义不符,
  无法点击下钻到城市;自定义徽章样式与品牌一致。
- 不做 DB 端聚合计数(百万级才需要;当前 668 家客户端聚合足够)。
