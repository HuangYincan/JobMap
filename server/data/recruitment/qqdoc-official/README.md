# qqdoc-official drops

JSON files for this source live in the private JobMap-data repository
(`recruitment/qqdoc-official/`). This public folder is README-only.

One file = one company with an official career URL from the reviewed Tencent Docs share. Override with `QQDOC_OFFICIAL_DIR` or `JOBMAP_DATA_DIR`. Missing, empty, or README-only input is not an authoritative snapshot.
