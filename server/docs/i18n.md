# 国际化 (i18n) 系统

## 概述

本项目实现了中英双语支持系统，可根据用户浏览器语言自动选择显示语言。

## 文件结构

- `/src/lib/i18n.ts` - 国际化配置和工具函数
- `/src/components/map-shell.tsx` - 使用国际化的主组件

## 使用方法

### 1. 添加新的翻译文本

在 `i18n.ts` 的 `translations` 对象中添加：

```typescript
export const translations = {
  // ... 现有翻译
  newKey: {
    zh: '中文文本',
    en: 'English text',
  },
}
```

### 2. 在组件中使用

```typescript
import { bilingual, t, type Language } from "@/lib/i18n";

// 双语显示（中文 English）
<span>{bilingual('layers')}</span>  // 输出: "图层 Layers"

// 单语显示
<span>{t('layers', lang)}</span>  // 根据 lang 输出: "图层" 或 "Layers"
```

## 当前实现

### 自动语言检测
- 使用 `getBrowserLanguage()` 检测浏览器语言
- 中文浏览器 → 显示中文
- 其他语言 → 显示英文

### 显示方式
- **侧边栏展开状态**: 双语显示 "图层 Layers"
- **tooltip 悬浮提示**: 单语显示（根据用户语言）
- **搜索框 placeholder**: 单语显示
- **aria-label 无障碍标签**: 单语显示

## 未来扩展

### 添加语言切换功能

可以在设置面板中添加语言切换选项：

```typescript
// 在 settings 按钮的点击事件中
<select value={lang} onChange={(e) => setLang(e.target.value as Language)}>
  <option value="zh">中文</option>
  <option value="en">English</option>
</select>
```

### 保存用户偏好

```typescript
// 保存到 localStorage
useEffect(() => {
  localStorage.setItem('preferred-language', lang);
}, [lang]);

// 初始化时读取
useEffect(() => {
  const saved = localStorage.getItem('preferred-language') as Language;
  if (saved) setLang(saved);
  else setLang(getBrowserLanguage());
}, []);
```

### 添加更多语言

```typescript
export type Language = 'zh' | 'en' | 'ja' | 'ko';  // 添加日语、韩语

export const translations = {
  search: {
    zh: '搜索',
    en: 'Search',
    ja: '検索',
    ko: '검색',
  },
  // ...
}
```

## 设计原则

1. **渐进式**: 从双语显示开始，便于后期切换到单语
2. **可扩展**: 易于添加新语言和新文本
3. **用户友好**: 自动检测浏览器语言，减少用户操作
4. **类型安全**: 使用 TypeScript 确保翻译键的正确性
